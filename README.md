# Pet Health Management and Social App

A mobile application developed as my **university thesis project** to help pet owners manage their pets' health information while providing social features for interaction and sharing through their phone with one touch.

The project combines **pet health management, social interaction, and cloud-based services** into one mobile platform.

## Overview

The application is designed to provide pet owners with a convenient way to:

* Manage pet profiles and personal information
* Record and manage pet health information
* Keep track of health-related records
* Organize important pet-related information
* Interact with other pet owners
* Share and communicate within the pet community
* Store application data using backend and cloud services

The project was developed as part of my **Computer Science and Technology bachelor's thesis**.

## Technologies I Used

### Mobile Application

* **React Native** - Cross-platform mobile application development
* **JavaScript / TypeScript** - Application logic and development
* **VS Code** - Development environment
* **Expo** - React native development and application tooling
* **Android Studio** - Android development, testing, and debugging

### Backend

* **Node.js** — Backend and server-side development
* **REST API** — Communication between the mobile application and backend

### Database

* **Supabase** — Storage and management of application data, jpg/png files

### Cloud Services

* **Alibaba Cloud (Aliyun)** — Cloud-based services and data management

## Project Architecture

The application follows a client-server architecture:

```text
┌─────────────────────────┐
│     React Native App    │
│      Mobile Client      │
└────────────┬────────────┘
             │
             │ REST API
             ▼
┌─────────────────────────┐
│       Node.js Server    │
│       Backend / API     │
└────────────┬────────────┘
             │
       ┌─────┴─────┐
       ▼           ▼
┌────────────┐ ┌─────────────┐
│  Supabase  │ │ Cloud       │
│  Database  │ │ Services    │
└────────────┘ └─────────────┘
```
